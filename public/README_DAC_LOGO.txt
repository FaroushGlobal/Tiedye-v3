# DAC Logo Instructions

You can place your actual DAC logo image file directly in the `/public` folder with any of these names:
- dac-logo.png (default recommended)
- dac-logo.svg
- dac-logo.jpg
- DAC logo2 (2).png

The app will automatically load and display your actual DAC logo in the header on the left of the Reflection tab!
If not yet uploaded or if loading, it displays a neat placeholder.
